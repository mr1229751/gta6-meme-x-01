# GTA 6 Meme — make.fun gta6-meme-x-01 entry

This repository is the entry package for make.fun's **gta6-meme-x-01** bounty, "Post a GTA 6 meme on X". The entry itself is a public post on X: a GTA 6 launch-week meme whose picture shows make.fun's ghost mascot on a Leonida boardwalk, captioned "WAITED 13 YEARS FOR GTA VI / SO MY AGENT IS PAYING FOR IT". The program here (`main.ts`, Node 22, standard library only) simply copies `POST.json` — the file naming the post's address on X — from the bot directory into the output directory for the house to read.
